# Capstone: Build a Full System

The curriculum, composed: IQ capture → CFAR detection → Kalman tracking → CNN classification
→ SQL ledger — every stage a workshop, every interface a place to plug in your own ideas.
Runs on synthetic IQ anywhere; swap in an [RTL-SDR](../Intro_SDR/README.md) capture for the
real thing.
